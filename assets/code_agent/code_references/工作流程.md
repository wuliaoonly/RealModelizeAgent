## 工作流程

### 第一步：理解需求

1. 读取建模分析文档：理解建模手的分析结果
2. 明确是画图需（figure）求还是建模求解需求（code）
3. 理解题目要求：读取题目文件，明确需要解决的问题

### 第二步：环境检查（必须先执行）

在编写任何代码之前，检查所选编程语言的运行时环境和依赖包。

**Python 环境检查**：
```python
# 检查 Python 版本
import sys
print(f"Python 版本: {sys.version}")

# 检查必需包
required_packages = [
    'numpy', 'pandas', 'matplotlib', 'scipy',
    'sklearn', 'statsmodels', 'openpyxl',
]

for package in required_packages:
    try:
        __import__(package)
        print(f"✅ {package} 已安装")
    except ImportError:
        print(f"❌ {package} 未安装，请运行: pip install {package}")
```

**检查规则**：
- 如果选择的运行时或必需的包不可用，**先报告确切的问题**，然后提供安装命令
- **不要因为环境问题而切换到另一种语言**（如 Python 不可用就改 MATLAB）
- 如果用户批准安装依赖，安装后继续；如果无法安装，报告阻碍并等待指示
- 可视化相关：确保 `matplotlib` 和 `pillow` 已安装（Python），或 `export_fig` 可用（MATLAB）

### 第三步：代码设计

1. **模块划分**: 将代码划分为清晰的功能模块
2. **数据结构**: 设计合理的数据结构和变量命名
3. **算法实现**: 确定具体的算法实现方法

### 第四步：代码实现

**代码运行与调试流程**：

```
编写代码 → 运行代码
  ↓
检查是否有报错？
  ├─ 有报错 → 直接在代码文件中修正 → 重新运行
  └─ 无报错 → 继续
  ↓
判断运行结果正确性
  ├─ 结果正确 → 完成
  └─ 结果错误 → 检查代码 → 在代码文件中修正 → 重新运行
```

**严禁投机取巧**：
- ❌ 禁止创建简化版代码（如 `问题一_简化版.py`）
- ❌ 禁止因报错而降低问题难度或更换不合适的算法
- ❌ 禁止更换算法逃避（因原算法报错而换成不合适的简单算法）

### 第五步：结果验证

每道题代码运行后必须进行结果验证：
- 结合题目要求检查结果
- 结合建模分析文档验证
- 结合运行效果检查可视化图表是否合理

### 第六步：迭代改进

如果结果不正确，必须先改进代码再进行下一个问题。

## 表格文件处理规范

| 表格类型 | 处理原则 |
|---------|---------|
| **题目附带输入表格** | 只读不写，禁止修改 |
| **结果输出表格** | 保持结构不变，只填写数据 |

**重要原则**：
- 使用 Excel 公式而非硬编码值

- 不添加/删除列或修改列名

- 输出到新文件，不覆盖原文件

- 使用 xlsx skill 的 recalc.py 重新计算公式

  ---

  ### 可视化代码编写原则

  **集成式可视化**：

  - 可视化代码可以与解决问题的主代码一起编写
  - 嵌入在数据处理的合适位置
  - 运行时可以实时获取数据和画图

  **3D图表使用**：

  - 在合适的场景下使用3D图表以增强视觉效果
  - 适用场景：多维数据展示、优化过程可视化、聚类结果展示等

  ### 可视化约束（重要）

  ```
  ┌─────────────────────────────────────────────────┐
  │  可视化约束（必须严格遵守）                      │
  ├─────────────────────────────────────────────────┤
  │  ⚠️  每个大图最多包含 2 个子图                  │
  │  ⚠️  禁止在一个大图中包含 3 个或更多子图         │
  │  ✅  如需展示多张图表，请分成多个独立图片文件    │
  └─────────────────────────────────────────────────┘
  
  正确：plt.subplots(1,2) 或 plt.subplots(2,1)
  错误：plt.subplots(2,3) 或 plt.subplots(3,3)
  ```

  **完整可视化规范参见**：`./roles/编程手/references/可视化规范.md`（含 Figure Contract、语义调色板、SVG导出、HTML面板生成）
