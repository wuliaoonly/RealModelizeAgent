# 提交前自查清单（CUMCM）

比赛最后 1 小时逐项打勾。括号里是常见雷区，务必注意。

## 一、论文本身

- [ ] 标题页：题目、队员信息、参赛号填写正确（无错别字、无缺字）
- [ ] 摘要：≤ 一页；包含【研究对象 + 总体思路 + 各问方法与关键结果 + 结论】；按「对于问题一/二/三」分段
- [ ] 关键词：3~5 个，与正文一致
- [ ] 正文字数 / 页数符合组委会要求（正文通常不超过 25 页，不含支撑材料；核对当年通知）
- [ ] 所有图表有编号、有题注、正文中有引用（图1 表1 编号不跳号）
- [ ] 所有公式有编号，正文引用了关键公式号
- [ ] 参考文献 8~15 篇，正文每篇都被 `\cite` 引用到
- [ ] ⚠️ 参考文献**没有**引用任何 AI 工具 / 大模型
- [ ] 符号说明表覆盖正文所有重要符号，且符号前后一致
- [ ] 模型假设条数与内容合理，与后文模型对应
- [ ] 无错别字、无遗留占位符（如「XXX」「待补充」「TBD」）
- [ ] 附录代码能跑通、与正文结果一致
- [ ] PDF 用阅读器打开检查：无乱码、无缺图、目录页码正确

## 二、支撑材料

- [ ] 代码文件齐全（按问题拆分命名清晰，如 `q1_xxx.m`、`q2_xxx.py`）
- [ ] 数据表格齐全（原始数据 + 处理后数据分开）
- [ ] 关键图表单独导出（高清 PNG/PDF）
- [ ] 支撑材料总大小 ≤ 20MB（压缩图片，删掉中间过程文件）
- [ ] ⚠️ 支撑材料中**不包含**可识别队员/学校信息的内容

## 三、打包与提交

- [ ] 论文 PDF 命名符合组委会要求（通常为「参赛编号.pdf」，核对当年通知）
- [ ] 支撑材料命名符合要求（通常为「参赛编号-支撑材料.zip」）
- [ ] 上传到指定系统后，**下载回来打开验证**（防止上传损坏）
- [ ] 保留一份本地备份（建议同步到网盘/邮箱）

## 四、时间线建议

| 时间点 | 事项 |
|---|---|
| 截止前 3 小时 | 论文定稿，不再大改内容，只做格式与错别字检查 |
| 截止前 1 小时 | 完成上表全部自查，打包 |
| 截止前 30 分钟 | 上传 + 下载验证，截图留证 |
