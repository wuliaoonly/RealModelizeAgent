# 全国大学生数学建模竞赛（CUMCM）论文 LaTeX 模板

一套**开箱即用**的国赛论文 LaTeX 模板，已按国赛排版要求（A4、宋体小四正文、黑体标题、三线表、上标引用）配置好，拿到新题直接往里填内容即可编译出 PDF。

## 一、文件夹结构

```
数模论文模板/
├── main.tex             ← 论文主文件（所有正文都写在这里）
├── references.bib       ← 参考文献数据库
├── SIMLI.TTF            ← 可选艺术字体（隶变，未使用不影响编译）
├── lishugbk.ttf         ← 可选艺术字体（隶书，未使用不影响编译）
├── Pictures/
│   ├── 说明.txt
│   ├── 流程图示例.jpg   ← 模板示例图（main.tex 中引用，可替换/删除）
│   ├── Preparation/     ← 数据预处理相关图片
│   ├── Question1/       ← 问题一图片
│   ├── Question2/       ← 问题二图片
│   └── Question3/       ← 问题三图片
└── README.md            ← 本说明
```

## 二、编译方法（必须用 XeLaTeX）

**本地 TeX Live（推荐）：**
```bash
latexmk -xelatex main.tex
```
或者手动编译两次（第一次生成目录和参考文献，第二次正常）：
```bash
xelatex main.tex
xelatex main.tex
```

**Overleaf：**
1. 上传本文件夹（或只传 `main.tex`、`references.bib`、`Pictures/`、两个字体文件）；
2. 菜单 → 编译器 选择 **XeLaTeX**；
3. 点击重新编译。

> 若报错找不到字体，把 `SIMLI.TTF`、`lishugbk.ttf` 删掉即可（正文未使用它们）。

## 三、使用流程（拿到新题后）

1. **填题目**：改 `main.tex` 开头居中那行，换成本次赛题标题。
2. **写摘要**：按模板里「对于问题一 / 问题二 / 问题三」的结构写，每段给出方法与关键结果。
3. **逐节填正文**：问题重述 → 问题分析 → 模型假设 → 符号说明 → 数据处理 → 模型建立和求解 → 模型评价 → 模型推广。
4. **插图**：图片放到 `Pictures/` 对应文件夹，正文用
   `\includegraphics[width=0.9\textwidth]{Pictures/Question1/你的图.png}` 引用。
5. **加文献**：往 `references.bib` 添加条目，正文用 `\cite{键名}` 引用，编译两次后自动编号。
   ⚠️ 不要引用任何 AI 工具（ChatGPT、DeepSeek 等），会被判违规。
6. **贴代码**：附录里有代码块模板，把各题求解代码按题目粘贴进去。
7. 用 `提交清单.md` 逐项自查后，按组委会要求打包提交。

## 四、模板里已配好的格式

| 项目 | 格式 |
|---|---|
| 页面 | A4，上下 2.54cm，左右 3cm |
| 正文字号 | 宋体小四，首行缩进 2 字符 |
| 一级标题 | 黑体四号居中，编号「一、二、三」 |
| 二级标题 | 宋体小四顶格加粗，编号 1.1、1.2 |
| 三级标题 | 黑体小四缩进 2 字符加粗，编号 1.1.1 |
| 表格 | 三线表（booktabs），固定位置 |
| 图 | 固定位置，支持并排子图（subfigure） |
| 引用 | 上标数字引用，[1][2] 样式（natbib + unsrtnat） |
| 代码 | listing 排版，带行号和边框 |

## 五、常见问题

- **公式不编号/编号跳号**：删掉 `main.aux` 后重新编译两次。
- **图片找不到**：检查路径是否从 `main.tex` 所在目录写起（如 `Pictures/Question1/1.png`）。
- **目录不显示**：正文默认不含目录（国赛不需要）；需要的话取消 `main.tex` 中
  `% \tableofcontents` 前的注释。
- **想用 Word 交稿**：本模板的章节结构可直接照搬到 Word，格式对照第四节表格即可。
